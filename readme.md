### Маппер данных для дашборда

Цель: Реализовать универсальный маппер, который преобразует вложенный объект с объектами в плоский массив объектов с дополнительными полями.

Исходные данные находятся в файле

```
src/payload.ts
```

Напишите функцию salesMapper, которая преобразует salesData в массив вида:

```javascript
[
  {
    region: 'Moscow', // Начало строки с заглавной буквы
    total: 150000,
    orders: 45,
    avgOrder: 3333,
    regionGrowth: '+25%', // Рассчитываем на основе total относительно самого низкого и высокого значения
    sliceDate: "2025-12-01T00:00:00.000Z", // Преобразовываем дату в ISO строку
    status: 'success' // 'success' если orders >= 30, иначе 'warning'
  },
  // ...
]
```
